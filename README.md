# Jewel Level Scatter Tuning

[English](README_EN.md) | 简体中文

一个面向像素宝石分类关卡的 Codex Skill，用于分析成品图、设计可玩的预填充盘面，并通过规则校验与 AI 视觉复核，兼顾可玩性、画面结构和产出稳定性。

## 产出背景

本 Skill 产出于我在 **北京知行远科技有限公司担任关卡策划** 期间。工作中，我发现随机散点容易破坏画面结构，人工调优耗时且验收标准不一致，因此与 AI 协作，将关卡分类、规则排序、脚本校验和视觉复核沉淀为可复用流程，用于提升关卡产出效率与准确率。

## 主要能力

- 根据成品像素图分析关卡结构并选择设计策略
- 生成兼顾合法性、可读性与视觉聚类的初始盘面
- 使用确定性脚本检查颜色、连通性和散点质量
- 结合 AI 视觉复核与编辑器终态校验，降低错配和返工
- 保存分析、配置、盘面与验证报告，支持稳定恢复和复盘

## 使用方式

将本目录安装到 Codex skills 目录后，在相关任务中调用：

```text
$jewel-level-scatter-tuning
```

完整流程与约束见 [SKILL.md](SKILL.md)。部分能力依赖公司内部 KStage 编辑器及相应访问权限。
